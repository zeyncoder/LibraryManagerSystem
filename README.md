# Library Management System

A RESTful Library Management System built with Spring Boot. The project provides CRUD operations for managing books, authors, and members.

## Technologies
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- MapStruct
- Lombok
- Swagger/OpenAPI
- Gradle

## Features
- CRUD operations for Books, Authors, and Members
- Input validation
- Global exception handling
- Pagination and sorting
- API documentation with Swagger

## Run the Project

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Configure the PostgreSQL database in `application.yml`.

3. Run the project:
```bash
./gradlew bootRun
```

## API Documentation

Swagger UI:
```
http://localhost:8080/swagger-ui/index.html
```
